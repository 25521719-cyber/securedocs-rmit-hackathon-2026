# Product requirements

- Match the reference sidebar, workspace banner, document list, editor, preview and sharing drawer, Settings / Integration Readiness, and five-step presenter flow.
- Manage public demo documents across local server restarts: create, list, search, edit, delete, request access, approve, and revoke.
- Show the intended Owner, Collaborator, and Administrator behavior. Owner can edit and grant; collaborator reads after a grant; administrator has metadata only.
- Clearly label every simulated role and access result. Never claim authentication, encryption, or secure storage without verification.
- Keep real document endpoints closed until TideCloak and an encryption/storage design are verified.

The handoff screenshots and notes define the visual reference. Real TideCloak configuration, client registration, license status, and production storage are TBD.
